LSTM Architecture

Long Short-Term Memory networks introduce three gates (Forget Gate, Input Gate, Output Gate) and an internal Cell State vector \(C_t\) that prevents vanishing gradients over extended trading intervals.

GRU Architecture

Gated Recurrent Units streamline recurrent computation by combining cell and hidden state using two gates: Update Gate and Reset Gate, training faster with fewer parameters.

Evaluation Methodology

Root Mean Squared Error (RMSE) serves as the primary benchmark because it penalizes extreme forecasting errors, crucial for algorithmic risk management.

Recursive Forecasting

Multi-step projections feed each predicted closing price back into the rolling feature window to simulate market continuity across 1, 5, 7, and 30-day horizons.
